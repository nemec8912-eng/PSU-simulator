# Симулятор блоков питания

Интерактивные анимированные схемы импульсных блоков питания для изучения работы и тренировки ремонта. Сейчас есть две платы:

| Страница | Плата | Деталей | Задач |
|---|---|---|---|
| `index.html` | Блок питания телевизора Samsung (типовая архитектура BN44): фильтр, мост, PFC, дежурка 5 В, включение PS-ON, LLC 13/24 В | 77 | 21 + случайные |
| `adapter.html` | Сетевой адаптер 12 В 2 А на UC3842 (флайбэк): пуск через резистор, подпитка от обмотки, ОС на TL431 + PC817 | 38 | 13 + случайные |
| `extra/psu-basics.html` | Основы: блок-схема и принцип работы | — | — |

## Что умеет

- **Анимация тока.** Точки на проводах показывают направление и момент протекания тока, цвет провода — тип напряжения. Ключи открываются и закрываются, диоды проводят по очереди.
- **Два вида.** «Схема» — принципиальная схема по участкам. «Плата» — детали в настоящих корпусах, сгруппированные по узлам. На плате видны повреждения, заметные глазом: вздутые конденсаторы, обгоревшие резисторы, тёмный предохранитель, трещины.
- **Режим «Обучение».** Любую деталь можно вывести из строя. Карточка объясняет, почему цепь перестала работать, какие будут признаки и почему деталь обычно выходит из строя.
- **Приборы.**
  - Мультиметр: V⎓, V~, Ω, прозвонка, диод, ёмкость.
  - ESR-метр.
  - Осциллограф: форма сигнала на выбранном выводе.
  - Тестер деталей: только для выпаянной детали в корзине.
  - Тепловизор: показывает нагрев деталей.
  - Сопротивление и диоды меряются только на обесточенной плате с разряженным C1.
- **Лабораторный БП.** Подаёт напряжение на шину при выдернутой вилке. При КЗ на шине срабатывает ограничение тока, а тепловизор показывает, какая деталь греется.
- **Лампа 100 Вт.** Включение в сеть через лампу: при КЗ лампа горит ярко, а предохранитель остаётся цел.
- **Режим «Ремонт».**
  - Задачи со скрытой поломкой, цепочки поломок (если устранить только следствие, деталь сгорит снова), случайные поломки на 1 или 2 детали.
  - Подсказки открываются по одной.
  - Деталь перетаскивается в корзину и проверяется. Замена перетаскивается из каталога. Неподходящая деталь не помогает или сгорает.
  - Очки, звёзды и история ремонтов. Незаконченная задача сохраняется в браузере и продолжается после перезагрузки.
- **Звуки:** хлопок при КЗ, тиканье, щелчки реле, писк прозвонки.
- **Телефон.** Касание выбирает деталь; выпайка — кнопкой в карточке, установка — касанием в каталоге.

## Как запустить

Откройте `index.html` в браузере, сервер не нужен. Онлайн-версия — через GitHub Pages: `https://nemec8912-eng.github.io/PSU-simulator/`.

Чтобы собрать страницу в один файл (например, отправить кому-то): `python3 tools/build.py adapter.html dist/adapter.html`.

## Структура

```
index.html, adapter.html   страницы плат (одинаковая разметка, разные файлы платы)
css/style.css              оформление, светлая и тёмная темы
js/core/                   общий движок, одинаковый для всех плат
  01-helpers.js            SVG-функции, общее состояние st, журнал
  04-render.js             отрисовка условных обозначений и проводов
  06-loop.js               анимация тока каждый кадр
  07-kit.js                варианты замены деталей (по типу и номиналу)
  08-workshop.js           режим ремонта: корзина, каталог, перетаскивание
  09-instruments.js        приборы: мультиметр, ESR, осциллограф, тестер
  10-ui.js                 карточка детали, кнопки, масштаб
  11-extras.js             тепловизор, лампа, ЛБП, звуки, случайные задачи, очки, сохранение
  12-pcb.js                вид «Плата»
boards/<плата>/            всё, что относится к одной плате
  parts.js                 BOARD (названия кнопок и текстов), база деталей P, уточнения комплекта замены
  schematic.js             участки PAN и схема SCH: координаты деталей и проводов
  sim.js                   модель работы: sim(), цепи nets(), каскадные поломки CASC, шины ЛБП LAB_RAILS
  scenarios.js             задачи SCEN, цепочки, список для случайных поломок, нагрев heatTarget()
  probe.js                 выводы деталей PINS, напряжения узлов NODE(), формы сигналов wave()
  device.js                что видно на устройстве: renderTv()
tools/build.py             сборка страницы в один HTML-файл
```

## Как развивать

**Добавить задачу.** Допишите объект в `SCEN` в `boards/<плата>/scenarios.js`:

```js
{t:"Короткое название", c:"Жалоба владельца", F:{C7:"dry"}, fuse:false,
 h:["Подсказка 1","Подсказка 2","Подсказка 3"], a:"Правильный ответ"}
```

`F` — какие детали неисправны и как (`open`, `short`, `dry`, `dead`, `drift`). Для цепочки добавьте `chain:1`. Каскад, который убивает деталь повторно, описывается в `CASC` в `sim.js`.

**Добавить поломку детали.** В `parts.js` у детали в последнем объекте добавьте режим `[почему не работает, [признаки], почему выходит из строя]`. Затем учтите его в `sim()`. Если поломка должна попадать в случайные задачи, добавьте пару `["ID","режим"]` в `RANDOM_POOL`.

**Добавить деталь.** Опишите её в `parts.js`, поставьте на участок в `schematic.js` (тип, координаты выводов `a`/`b`), подключите провода (`w`) к цепи. Для приборов добавьте выводы в `PINS` (`probe.js`). На виде «Плата» деталь появится сама.

**Добавить новую плату.**
1. Скопируйте папку `boards/adapter` в `boards/<новая>` и `adapter.html` в `<новая>.html`.
2. В HTML замените путь `boards/adapter/` на новый, поправьте заголовки.
3. Добавьте ссылку в навигацию (`<nav class="boards">`) на всех страницах.

Предохранитель должен называться `F1`, сетевой конденсатор — `C1`: на эти имена опираются движок и кнопка разряда.

## Оговорка

Схемы собраны по типовым архитектурам, номиналы и позиционные обозначения типичные — на конкретной плате они отличаются. Модель учебная, это не SPICE-симуляция.
