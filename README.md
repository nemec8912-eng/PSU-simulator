# Симулятор блока питания ТВ Samsung

Интерактивная анимированная схема импульсного блока питания телевизора Samsung (типовая архитектура серии BN44) для изучения работы и ремонта.

- Полная принципиальная схема: 77 деталей, разбитых на 9 участков: вход и фильтр, мост, PFC, дежурка 5 В, включение PS-ON, LLC 13/24 В, обратные связи.
- Анимация тока: точки на проводах показывают направление и момент протекания тока, цвет провода — тип напряжения.
- **Режим «Обучение»:** любую деталь можно вывести из строя (обрыв, пробой, высыхание). Карточка объясняет, почему цепь перестала работать, какие будут признаки и почему деталь выходит из строя.
- **Режим «Ремонт»:** 15 задач со скрытой поломкой.
  - Видна только жалоба владельца и то, докуда идёт ток. Подсказки открываются по одной, по нажатию.
  - Деталь перетаскивается мышкой в корзину и проверяется там мультиметром.
  - Замена перетаскивается из каталога (145 позиций) на пустое место. Неподходящая деталь не помогает или сгорает.
  - После ремонта ТВ включается пультом: если всё исправно, экран показывает картинку.

## Как запустить

Откройте `index.html` в браузере, сервер не нужен.

Чтобы симулятор открывался по ссылке, включите GitHub Pages: **Settings → Pages → Source: Deploy from a branch → `main` / root**. Адрес будет вида `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
index.html            разметка страницы
css/style.css         оформление: цвета, светлая и тёмная темы
js/01-helpers.js      общие функции (создание SVG, форматирование)
js/02-parts.js        база деталей: название, номинал, назначение, проверка, режимы поломок с текстами
js/03-schematic.js    схема: координаты деталей, провода, флаги цепей по 9 участкам
js/04-render.js       отрисовка условных обозначений (резистор, диод, MOSFET, микросхема…)
js/05-sim.js          модель работы: как поломки влияют на напряжения и ток, каскадные поломки
js/06-loop.js         анимация: движение тока, подсветка деталей каждый кадр
js/07-kit.js          варианты замены для каждой детали (подходит / не подходит / сгорит позже)
js/08-workshop.js     режим ремонта: задачи, подсказки, корзина, каталог, перетаскивание
js/09-ui.js           карточка детали, панель состояния ТВ, кнопки
extra/psu-basics.html первый, упрощённый вариант: блок-схема и принцип работы
```

Скрипты подключаются по порядку и делят общие глобальные переменные. Сборщик не нужен.

## Как развивать

**Добавить задачу для ремонта** — допишите объект в массив `SCEN` в `js/08-workshop.js`:

```js
{t:"Короткое название", c:"Жалоба владельца", F:{C7:"dry"}, fuse:false,
 h:["Подсказка 1","Подсказка 2","Подсказка 3"], a:"Правильный ответ"}
```

`F` — какие детали неисправны и как (`open`, `short`, `dry`, `dead`, `drift`). Режим должен быть описан у детали в `js/02-parts.js`.

**Добавить новую поломку детали** — в `js/02-parts.js` у детали в последнем объекте добавьте режим `[почему не работает, [признаки], почему выходит из строя]`. Затем учтите его в `js/05-sim.js` (функция `sim`): там решается, что перестаёт работать.

**Добавить деталь на схему** — опишите её в `js/02-parts.js`, поставьте на нужный участок в `js/03-schematic.js` (тип, координаты выводов `a`/`b`) и подключите провода (`w`) к нужной цепи.

**Изменить варианты замены** — функция `kitFor` в `js/07-kit.js`.

## Оговорка

Схема собрана по типовой архитектуре блоков Samsung BN44: PFC на FAN7930, дежурка на ICE3BR0665J, LLC на FAN7621 с внешними ключами. Позиционные обозначения и номиналы типичные. На конкретной плате они будут отличаться. Модель упрощённая и учебная, это не SPICE-симуляция.
